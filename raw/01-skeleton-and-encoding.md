# 01. 骨架與編碼 (Skeleton and Encoding)

歡迎來到前端開發的第一步！在學習任何華麗的特效之前，你必須先理解網頁的「地基」是如何搭建的。

一個網頁檔案本質上就是一個**純文字檔**，但為了讓瀏覽器（如 Chrome, Safari）知道這是一個網頁而並非一般的記事本，我們需要遵循一套特定的標準規範。

---

## 1. 建立你的第一個 HTML 檔案

請在你的電腦上建立一個資料夾，並在裡面建立一個名為 `index.html` 的檔案。

**為什麼叫 `index`？** 
因為根據伺服器的約定，當使用者訪問一個網站（例如 `https://example.com/`）而沒有指定具體檔案時，伺服器會**自動尋找**名為 `index.html` 的檔案作為首頁。

### 🚀 最簡單的 HTML 骨架 (Hello World)
請將以下代碼複製到你的 `index.html` 中，並用瀏覽器打開它：

```html
<!DOCTYPE html>
<html lang="zh-Hant">
<head>
    <meta charset="UTF-8">
    <title>我的第一個網頁</title>
</head>
<body>
    <h1>你好，世界！</h1>
    <p>這是我學習前端工程師的第一步。</p>
</body>
</html>
```

---



## 1.5 秘密筆記：HTML 註解 (Comments)

HTML 的註解讓我們可以在代碼中留下筆記，而這些筆記 **不會** 在瀏覽器畫面中顯示。

**語法：** `<!-- 這裡寫你的筆記 -->`

**🚀 實作範例：**
```html
<!-- 這是我的導航欄區域，之後要改成深藍色 -->
<nav>
    ...
</nav>

<!-- 
這裡可以寫多行註解
適合用來記錄複雜的結構說明 
-->
```

**專業技巧：**
- **標記區塊**：在大型檔案中使用 `<!-- Section Start: About Me -->` 和 `<!-- Section End: About Me -->`，讓你能快速定位。
- **暫時關閉**：如果你不確定某段代碼是否導致錯誤，可以用註解把它「包裹」起來，讓它失效而不用刪除。

## 2. 深度解析：每一行代表什麼？

對於初學者來說，這些標籤看起來像符號，但它們每一行都有極其重要的作用：

### A. `<!DOCTYPE html>` (文檔類型聲明)
- **它是什麼**：這不是一個 HTML 標籤，而是一個「聲明」。
- **作用**：告訴瀏覽器：「請使用 **HTML5** (目前最新的標準) 來解析這個頁面」。
- **如果沒寫會怎樣？** 瀏覽器會進入 **「怪異模式 (Quirks Mode)」**，這會導致你的網頁在不同瀏覽器中顯示得完全不同，佈局會莫名其妙地崩潰。

### B. `<html lang="zh-Hant">` (根元素)
- **作用**：定義整個網頁的內容。`lang="zh-Hant"` 告訴瀏覽器和搜尋引擎：這個頁面是用 **繁體中文** 撰寫的。
- **專業視角**：這對 SEO 和螢幕閱讀器 (Accessibility) 非常重要，它能讓 Google 更精確地將你的網頁推薦給正確的語言用戶。

### C. `<head>` (元數據區)
- **作用**：這裡存放的是**「給瀏覽器看的資訊」**，使用者在網頁正文中看不到這裡的內容。
- **常見用途**：設定編碼、定義標題、引入 CSS 樣式表、設定 SEO 標籤。

### D. `<body>` (內容區)
- **作用**：這裡存放的是**「給使用者看的內容」**。所有你在螢幕上看到的文字、圖片、按鈕，全部都必須放在 `<body>` 之內。

---

## 3. 核心重點：為什麼必須設定 `<meta charset="UTF-8">`？

這是初學者最容易忽略，但也是最容易導致慘劇的設定。

### 什麼是 UTF-8？
`UTF-8` 是一種 **「字符編碼 (Character Encoding)」**。簡單來說，電腦只認識 0 和 1，它需要一張「對照表」來知道 `01000001` 代表的是字母 `A` 還是中文的 `你`。

- **UTF-8** 是目前全球統一的標準對照表，它包含了世界上幾乎所有語言的字符。

### ❌ 如果沒設定 UTF-8 會發生什麼？ (亂碼危機)
如果你在 HTML 中寫了中文，但沒有設定 `UTF-8`，瀏覽器可能會使用舊的編碼 (例如 `Windows-1252` 或 `Big5`) 來讀取。
- **結果**：你的「你好」會變成 `你好` $\rightarrow$ `??` 或 `SòSò`。這就是著名的 **「亂碼 (Mojibake)」** 現 phenomena。

**專業習慣**：永遠在 `<head>` 的第一行就寫上 `<meta charset="UTF-8">`，確保你的網頁在全世界任何一台電腦上打開，中文都顯示正常。

## 🛠️ 主專案功能疊加

現在，請將上述知識應用到你的『專業個人品牌網站』中：

1. **建立地基**：建立 `index.html` 並設定 UTF-8 編碼。
2. **定義語言**：設定 `html` 標籤的 `lang` 為 `zh-Hant`。
3. **建立骨架**：寫出基礎的 `<head>` 與 `<body>` 結構。
