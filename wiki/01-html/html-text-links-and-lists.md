# 文字與基礎標籤

> HTML 標籤應根據內容的性質選擇，而非為了達到視覺效果而隨意使用。

## 🎯 為什麼 (Why)

初學者常為了讓字變大而亂用 `<h1>`，這會嚴重影響 Google SEO 判斷。專業開發者根據內容性質選擇標籤，讓爬蟲與螢幕閱讀器正確理解頁面結構。

## 🧠 核心概念

### 標題層級 (`<h1>`–`<h6>`)

- `<h1>`：頁面最重要的主題，**每頁僅限一個**
- `<h2>`–`<h6>`：次要標題，層級越深字體通常越小，但**不要為了字體大小而濫用**

### 段落與格式化標籤

| 標籤 | 效語義 | 說明 |
|------|--------|------|
| `<p>` | 段落 | 自動加入段落間距 |
| `<strong>` | 重要 | 粗體，螢幕閱讀器加重語氣 |
| `<em>` | 強調 | 斜體，表示語意強調 |
| `<br>` | 強制換行 | 自閉合標籤 |
| `<hr>` | 主題分隔 | 水平分隔線 |

### 超連結 (`<a>`)

- `href`：目標 URL（絕對或相對路徑）
- `target="_blank"`：在新分頁開啟（避免使用者離開本站）

### 列表 (`<ul>`, `<ol>`, `<li>`)

- `<ul>`：無序列表，順序不重要
- `<ol>`：有序列表，有步驟順序

## 💻 Code Snippet

```html
<!-- 正確的標題層級結構 -->
<h1>我的專業攝影作品集</h1>
<h2>風景攝影</h2>
  <h3>山脈系列</h3>
  <h3>海洋系列</h3>
<h2>人像攝影</h2>
  <h3>商業人像</h3>

<!-- 帶標籤綁定的表單輸入 -->
<label for="user-email">電子郵件：</label>
<input type="email" id="user-email" name="email" required>
```

## ⚠️ 避坑對比 (❌ vs ✅)

| ❌ 錯誤做法 | ✅ 正確做法 |
|------------|------------|
| 為了字變大而用 `<h1>` | 根據語義選擇標題層級，用 CSS 調整字體大小 |
| 每頁多個 `<h1>` | 每頁僅限一個 `<h1>`，其餘用 `<h2>`–`<h6>` |
| 超連結沒設定 `target="_blank"` | 外部連結加上 `target="_blank"`，保留使用者在本站 |
| 只用 `<div>` 做標題 | 使用 `<label>` 綁定輸入框，提升可用性與 A11y |
