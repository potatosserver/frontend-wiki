# 運算符與控制流程

> 儲存數據後，需要透過運算符加工與控制流程做邏輯判斷，程式才具備「思考」能力。

## 🎯 為什麼 (Why)

只能儲存數據的程式只是記事本。運算符與控制流程讓程式能做抉擇（if/else）與重複執行（迴圈），這是邏輯程式設計的基礎。

## 🧠 核心概念

### 運算符

| 類型 | 運算符 | 說明 | 推薦 |
|------|--------|------|------|
| 算術 | `+ - * / %` | 加減乘除與取餘數 | 基礎計算 |
| 比較 | `=== !== > < >= <=` | 結果為布林值 | **永遠用 `===` 嚴格相等** |
| 邏輯 | `&& || !` | 與/或/非 | 複合條件判斷 |

### `==` 與 `===` 陷阱

- `==`：鬆散相等，會自動轉換型別（`"5" == 5` 為 `true`），易導致 Bug
- `===`：嚴格相等，數值與型別都必須相同，**專業推薦永遠使用 `===`**

### 控制流程

#### if / else (分支)

```javascript
let age = 18;
if (age >= 18) {
    print("✅ 你已成年");
} else if (age >= 12) {
    print("⚠️ 你是青少年");
} else {
    print("❌ 你太小了");
}
```

#### 迴圈

| 迴圈 | 適用場景 | 語法結構 |
|------|----------|----------|
| `for` | 已知執行次數 | `for (let i = 1; i <= 5; i++)` |
| `while` | 條件成立就繼續 | `while (energy > 0)` |

**⚠️ while 陷阱**：忘記改變條件變數會造成「死迴圈」，導致瀏覽器卡死。

## 💻 Code Snippet

```javascript
// 算術運算
let a = 10, b = 3;
print("加法: " + (a + b));   // 13
print("餘數: " + (a % b));   // 1

// 年齡檢查器
let age = 18;
if (age >= 18) {
    print("✅ 你已成年，可以進入本網站。");
} else {
    print("❌ 你太小了，請先詢問家長。");
}

// for 迴圈：印出 1 到 5
for (let i = 1; i <= 5; i++) {
    print("這是第 " + i + " 次重複執行");
}

// while 迴圈：倒數
let energy = 3;
while (energy > 0) {
    print("正在工作... 能量剩餘: " + energy);
    energy--;
}
print("能量耗盡，休息時間！");
```

## ⚠️ 避坑對比 (❌ vs ✅)

| ❌ 錯誤做法 | ✅ 正確做法 |
|------------|------------|
| 用 `==` 比較 | 永遠用 `===` 嚴格相等 |
| while 迴圈忘記改變條件變數 | 確保迴圈內會修改條件變數，避免死迴圈 |
| 在 if 嵌套過深 | 適當使用早期返回 (early return) 簡化邏輯 |
| 用 for 迴圈處理陣列 | 後續學 `.map()`/`.filter()`/`.forEach()` 更簡潔 |
