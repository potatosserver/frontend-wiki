單元 1 · HTML

HTML 骨架與語義化無障礙

建立網頁的「地基」。理解 HTML5 基礎結構、編碼設定與語義化標籤，避免亂碼、Quirks Mode 與 Div Soup。

🦴 HTML5 骨架

每個網頁都應以 <!DOCTYPE html> 開頭，觸發瀏覽器標準模式，避免進入 Quirks Mode 導致佈局崩潰。

wiki/01-html/html-skeleton-and-encoding.md

🔤 UTF-8 編碼

永遠在 <head> 第一行設定 <meta charset="UTF-8">，防止中文顯示為亂碼 (Mojibake)。

wiki/01-html/html-skeleton-and-encoding.md

🏷️ 語義化標籤

擺脫 Div Soup，使用 <header>、<nav>、<main>、<footer> 等標籤，提升 SEO 與無障礙支援。

wiki/01-html/html-semantics-and-a11y.md

♿ 無障礙 (A11y)

所有圖片加上有意義的 alt，輸入框綁定 <label>，讓螢幕閱讀器與 Google 爬蟲都能正確理解內容。

wiki/01-html/html-semantics-and-a11y.md

❌ 錯誤做法

  • 缺少 <!DOCTYPE html>
  • 中文頁面沒設定 lang
  • 所有區塊都用 <div>
  • 圖片沒有 alt 屬性

✅ 正確做法

  • 第一行寫 <!DOCTYPE html>
  • 設定 lang="zh-Hant"
  • 使用語義化標籤（header / main / footer）
  • 所有 img 加上 alt 描述
HTML5 語義化範例 · wiki/01-html/html-semantics-and-a11y.md 
<!DOCTYPE html>
<html lang="zh-Hant">
<head>
    <meta charset="UTF-8">
</head>
<body>
    <header><nav>...</nav></header>
    <main><article>...</article></main>
    <footer>...</footer>
</body>
</html>
📚 知識來源：wiki/01-html/html-skeleton-and-encoding.md、wiki/01-html/html-semantics-and-a11y.md
單元 2 · CSS

CSS 佈局與現代避坑指南

掌握盒模型、選擇器特異度、Flexbox 與 Grid，學習如何避免佈局爆掉、z-index 沒效與手機端 100vh 陷阱。

📦 Box Model

盒子由內到外分為 Content、Padding、Border、Margin 四層。務必設定 * { box-sizing: border-box; } 讓寬度計算更直覺。

wiki/02-css/css-box-model-and-units.md

🎯 選擇器特異度

標籤選擇器 1 分、類選擇器 10 分、ID 選擇器 100 分。權重最高的樣式會贏，避免亂用 !important。

wiki/02-css/css-selectors-and-specificity.md

🌀 Flexbox

用 display: flex 搭配 justify-content 與 align-items 實現完美對齊，gap 統一管理子元素間距。

wiki/02-css/css-flexbox-layout.md

📐 CSS Grid

二維佈局的指揮官。用 repeat(auto-fill, minmax(250px, 1fr)) 實現無需 Media Query 的自適應作品集牆。

wiki/02-css/css-grid-layout.md

❌ 常見陷阱

  • 手機端用 100vh → 地址欄遮擋
  • 全站字體只用 px → 無法縮放
  • z-index 沒效 → 缺 position 設定
  • 佈局寬度固定 1200px → 出現橫向滾動條

✅ 專業做法

  • 改用 100dvh 動態視口高度
  • 基礎字體用 rem 支援 A11y
  • 確認元素有 position 與層疊上下文
  • 用 width: min(90%, 1200px) 流體寬度
Flexbox 動態視口居中配方 · wiki/02-css/css-flexbox-layout.md 
.center-box {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100dvh; /* 動態高度識別，避開手機網址列遮擋 */
}

單元 3 · JavaScript

JavaScript 核心與 Event Loop 運作機制

從變數、函數、DOM 操作到非同步與事件循環，理解 JS 如何在單執行緒下處理異步操作而不卡死瀏覽器。

📦 變數與型別

優先使用 const，只有會改變的數據才用 let。掌握 String、Number、Boolean 與 Null/Undefined。

wiki/04-js/js-basics-and-variables.md

⚡ 函數與閉包

箭頭函數是現代標準。閉包讓函數能記住創建時的環境，常用於建立私有計數器。

wiki/04-js/js-functions-scope-and-closures.md

🖱️ DOM 操作

用 querySelector 選中元素、addEventListener 監聽事件、classList.toggle 實作深色模式。

wiki/04-js/js-dom-manipulation.md

🔄 陣列高階函數

.filter() 篩選、.map() 轉換、.forEach() 執行動作，取代冗長的 for 迴圈。

wiki/04-js/js-arrays-objects-and-hof.md

🌀 Event Loop：微任務 vs 宏任務

JS 是單執行緒。Event Loop 不斷檢查 Call Stack，若為空則從 Task Queue 拿取任務。微任務 (Promise) 優先於宏任務 (setTimeout)。

Event Loop 執行順序驗證 · wiki/04-js/js-engine-and-event-loop.md 
console.log("1. 開始");

setTimeout(() => console.log("2. setTimeout (宏任務)"), 0);

Promise.resolve().then(() => console.log("3. Promise (微任務)"));

console.log("4. 結束");

// 輸出結果：1 → 4 → 3 → 2

❌ 錯誤做法

  • 主執行緒做大量計算 → 瀏覽器卡死
  • 以為 setTimeout(0) 立即執行
  • fetch 失敗沒有 try/catch 處理
  • 數據加載中頁面空白

✅ 正確做法

  • 用 setTimeout(..., 0) 拆分繁重任務
  • 理解微任務優先於宏任務
  • 用 try/catch 捕捉錯誤，顯示友善訊息
  • 顯示「加載中...」Loading 狀態
